# Spezifikationen

Hier liegt je Funktion eine Datei, die **vor** dem Code entstanden ist:
Ziel, Verhalten, Berechtigungen, Datenmodell, Tests.

Angelegt wird sie mit `/spec <kurze Beschreibung>`. Der Ablauf hält nach dem
Schreiben an und wartet auf Freigabe.

Warum schriftlich: Ein Sprachmodell füllt Lücken selbstständig und plausibel.
Steht vorher fest, was gebaut werden soll, fallen die Stellen auf, an denen
geraten wurde — nachher ist das schwer zu erkennen.

Die Dateien bleiben liegen. Sie beschreiben, warum etwas so gebaut wurde, und
sind beim nächsten Umbau mehr wert als ein nachträglicher Kommentar.
